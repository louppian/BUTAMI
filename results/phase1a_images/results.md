# Phase 1a. 일반 안경 / 스마트글래스 이미지 수집

## 목적과 범위

일반 안경과 스마트글래스 분류에 사용할 단일 제품 이미지를 수집한다. 목표는 일반 안경 500장과 스마트글래스 500장으로 총 1,000장이다. 이번 수집은 제품 이미지에 한정하며 착용 사진과 영상은 포함하지 않는다.

## 실행 준비

코드는 `code/phase1a_images/image_crawl.py`에 있다. Python 3.12 환경에서 `ddgs`, `requests`, `Pillow`, `torch`, `transformers`, `ImageHash`를 준비하고 IDE에서 파일을 실행한다. 별도 CLI 인자는 없다. 목표 수량과 검색어는 파일 상단에서 수정한다.

이미지 선별에는 `openai/clip-vit-base-patch32`를 사용한다. 최초 실행 시 모델 파일을 다운로드하며 `ckpt/pretrained/clip/`에 캐시한다. 이후에는 해당 캐시를 재사용한다. CUDA를 사용할 수 있으면 GPU, 그렇지 않으면 CPU에서 처리한다.

## 수집 흐름

### 1. 검색 후보 확보

일반 안경은 금속테·뿔테·무테·반무테·원형·사각형 등 형태별 검색어를 사용한다. 스마트글래스는 Ray-Ban Meta, XREAL, VITURE, Rokid, Bose, Echo Frames, Solos, Even Realities, Huawei 등 제품별 검색어를 사용한다.

각 검색어에서 페이지당 최대 100개의 후보를 조회하고 최대 5페이지까지 탐색한다. 검색어별 저장량을 제한해 한 제품이나 형태에 편중되는 것을 줄인다. 한 클래스가 500장에 도달하면 해당 클래스 수집을 종료한다. 검색 실패는 화면에 출력하고 다음 검색어로 진행한다. 제한된 검색 범위에서 후보가 부족하면 실제 저장 수량을 알리고 종료하며 목표 달성을 보장하지 않는다.

### 2. 이미지 로드와 기본 선별

이미지 URL의 중복 요청을 피하고 파일을 메모리에서 읽는다. 요청 실패, 손상 이미지, 20MB 초과 파일, 짧은 변이 256px 미만인 이미지를 제외한다. EXIF 방향을 반영하고 RGB로 변환한다.

### 3. 중복 제거

perceptual hash를 계산해 이미 저장한 이미지와 비교한다. 해밍 거리가 4 이하인 이미지는 유사 중복으로 제외한다. 두 클래스 전체를 비교하므로 같은 이미지가 양쪽에 중복 저장되지 않도록 한다. 다만 유사한 별도 제품도 제외될 수 있다.

### 4. 단일 제품 이미지 선별

CLIP으로 후보 이미지와 설명 문장들의 유사도를 비교한다. 안경 한 개가 온전히 한 번 등장하는 제품 사진이 가장 높은 점수를 받고, 설명 간 softmax 점수가 0.7 이상인 경우만 저장한다.

복수 안경, 여러 시점 합성, 광고·도면, 부분 확대, 착용 사진, 케이스·액세서리 묶음, 안경과 무관한 이미지는 제외 대상으로 설정한다. 이 점수는 설명 문장 사이의 상대 점수이며 정확한 개수 판정이나 보정된 확률이 아니다. 단일 제품 판별 오류가 있을 수 있다.

### 5. 이미지와 출처 저장

일반 안경은 `data/images/regular_glasses/regular_glasses_000001.jpg`, 스마트글래스는 `data/images/smart_glasses/smart_glasses_000001.jpg` 형식으로 저장한다. 해상도는 유지하고 RGB JPEG로 저장한다.

`results/phase1a_images/metadata.csv`에는 저장 경로, 클래스, 검색어, 이미지 URL, 출처 페이지 URL, 검색 결과 제목, 이미지 해시와 필터 점수를 기록한다. 이미지가 저장될 때마다 메타데이터를 기록한다. 이 문서는 작업 흐름을 설명하며 실행 통계로 덮어쓰지 않는다.

### 6. 이어받기와 검수

재실행하면 기존 이미지의 수량과 해시를 읽고 남은 목표 수량을 수집한다. 기존 파일을 덮어쓰지 않고 다음 번호부터 저장한다. 기존 메타데이터에서 실제 파일이 존재하는 URL은 재수집하지 않는다.

일반/스마트 라벨은 검색어에서 부여한 임시 라벨이다. CLIP 필터는 제품 정체나 스마트 기능을 검증하지 않으므로 제품 정보와 이미지 내용으로 별도 검수한다. 출처의 이용 조건도 확인한다. 검수한 이미지는 Phase 2a의 안경 영역 분할·feature 추출 입력으로 사용한다.

## 확인 상태

이 문서는 구현된 수집 절차를 기록한다. 서버에서 1,000장 수집과 라벨 검수가 완료되었다는 의미는 아니다.
